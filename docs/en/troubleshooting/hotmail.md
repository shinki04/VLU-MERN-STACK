You can use Gmail as an alternative because Hotmail is no longer supported by Microsoft for basic authentication (SMTP).

Read more here:
- [Nodemailer Issue #1685](https://github.com/nodemailer/nodemailer/issues/1685)
- [Nodemailer Issue #1485](https://github.com/nodemailer/nodemailer/issues/1485)
:::tip TIP 
  In addition to Gmail, you can use other SMTP platforms such as Mailtrap, Brevo, ...
:::

## Gmail Configuration

1. Log in to the Gmail account you want to use to send emails.

2. Open the [Google Account page](https://myaccount.google.com/).

3. Select the **Security** tab.

4. Scroll down to the **How you sign in to Google** section.

5. Find the **2-Step Verification** option.

6. Click on **2-Step Verification → Turn on**.

7. Google will ask you to confirm your account and set up a verification method. [Google Support](https://support.google.com/accounts/answer/185839?hl=en)

After successfully turning it on, do not stop there. Since our goal is to fix the Nodemailer error, the next step is to create an **App Password**.

You can open this page directly: [Google App Passwords](https://myaccount.google.com/apppasswords)

## App Password Configuration

### Open the App Passwords Page

Log in to the correct Gmail account you want to use to send emails, then open: [Google App Passwords](https://myaccount.google.com/apppasswords)

If Google asks you to log in again, please do so.

> **Note:** You must turn on 2-Step Verification first before the App Password feature can be used. Google explains that an App Password is a 16-character code used for applications that do not support modern login methods.

## Generate App Password

On the **App Passwords** page, find the section to generate a new password.

If the **App Name** field appears, enter any name:

```text
my-rest-api
```
Then click Create.

Google will provide you with a 16-character App Password:
```text
abcd efgh ijkl mnop
```
:::warning Note

This is just an example code. Do not use the code above.

You must use the actual App Password generated by Google for your account.

:::

## Add App Password to Your Configuration

There are 2 ways to configure the App Password in your `.env` file:

::: code-group

```text [Method 1: Remove Spaces]
PORT=3000
EMAIL=your_gmail_address
EMAIL_PASSWORD=app_password_without_spaces
```

```text [Method 2: Use Double Quotes]
PORT=3000
EMAIL=your_gmail_address
EMAIL_PASSWORD="abcd efgh ijkl mnop"
```

:::

- **Method 1 (Remove Spaces):** If Google provides the code `abcd efgh ijkl mnop`, you must manually remove the spaces and enter `abcdefghijklmnop`.
- **Method 2 (Use Double Quotes):** You put the entire password inside a pair of double quotes `" "`. The `.env` parser will automatically understand that the space is part of the password. Do not manually remove the spaces in the Node.js code, as Node.js will read the quoted string exactly as Google generated it.

## Update Configuration Code

Remember to update the configuration in the `server/utils/EmailUtil.js` file.
Most people agree that a common configuration is to set `secure: true` with port `465` or `secure: false` with port `587`.

Example:
```js
const transporter = nodemailer.createTransport({ // [!code focus]
  service: "hotmail",// [!code --] [!code focus]
  host: "smtp.gmail.com",  // [!code ++] [!code focus]
  port: 587,  // [!code ++] [!code focus]
  secure: false, // use false for STARTTLS [!code ++] [!code focus]
  auth: {
    user: process.env.EMAIL || MyConstants.EMAIL_USER,
    pass: process.env.EMAIL_PASSWORD || MyConstants.EMAIL_PASS,
  },
});
```

## Check .gitignore

Make sure you did this correctly:
```text
node_modules/
.env
```
This is very important because the `.env` file is not allowed to be uploaded to GitHub as it contains sensitive information including the App Password.

## Restart Node.js

Environment variables are only loaded when the application starts. Always restart Node.js after changing the `.env` file or source files.

If the terminal is running the server, press `Ctrl + C`.

Then run:
```bash
$ node server.js
```

If successful, you will see the log:
```text
The server is running at http://localhost:3000
SMTP server is ready.
```
